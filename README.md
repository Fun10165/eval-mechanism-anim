# 贪心链与 DoG · 机制动画

## 用途

在会议上向技术同事讲解长程任务的 Agent 评测机制：为什么要有贪心链、一个单元里怎么加跑与终止、判定器怎么判、DoG 怎么组合结论与只重判变化的部分。观众第一次接触这套机制，所以每一页只讲一件事，演讲者按键逐步推进，每一步一段动画加一句可以照着念的字幕。

## 设计

- 一份演示 = 若干场景；一个场景 = 一张 1920×1080 的 SVG 画布 + 一条 GSAP 时间线，时间线切成若干步。
- 播放器负责翻页、字幕、进度与缩放；场景只负责画图与排动画，互相独立。
- 任何时刻的画面只由播放头位置决定：「上一步」和直接打开某一步，都是把播放头放到那一步的结尾，不需要每个场景自己写倒放逻辑。
- 构建产物是一个自包含的 HTML 文件，现场断网也能打开。

## 场景

| 编号 | id | 内容 |
|---|---|---|
| 00 | `cover` | 封面 |
| 01 | `problem` | 我们究竟在测评什么：指令遵循的差异让比较失去对象 |
| 02 | `chain` | 贪心链：冻结起点 → 跑 n 份 → 判定 → 取 top-1 |
| 03 | `unit` | 一个单元里：起点份数、按倍率加跑、上限与终止 |
| 04 | `rounds` | 一份里：回合、收尾判定、网关故障不计入 |
| 05 | `judge` | 判定器：规则清单 → DoG 图 → 独立验证会话 → judge.json |
| 06 | `dog` | DoG：节点、两种判据、失败传播、整体断言 |
| 07 | `inherit` | 冻结与继承：改了什么就只重判什么 |
| 08 | `system` | 全景：七条链、共享判定器、看门狗与设备隧道 |
| 09 | `limits` | 它保证了什么、保证不了什么 |

## 使用

```bash
bun install
bun run dev          # 开发：http://localhost:5173
bun run build        # 产物：dist/index.html（单文件，可直接双击打开）
```

放映时按键：

| 按键 | 作用 |
|---|---|
| → / 空格 / PageDown / 鼠标左键 | 下一步；动画还在播时再按一次，直接跳到这一步的结尾 |
| ← / PageUp | 上一步（直接显示那一步的结尾） |
| Home / End | 本场景第一步 / 最后一步 |
| 0–9 | 跳到第 n 个场景 |
| O / Esc | 目录 |
| F | 全屏 |

翻页笔一般发送 PageUp / PageDown，可以直接用。

网址参数：`#<场景 id>/<步号>` 直接打开某一步；`?only=<文件名>`（例如 `?only=05-judge`）只加载一个场景，用于单独修改与预览。

## 细则

### 目录

- `src/main.ts`：播放器。
- `src/scene.ts`：场景契约（`id`、`title`、`kicker`、`bare`、`build`）。
- `src/scenes/NN-<id>.ts`：场景文件，按文件名顺序自动收集，新增场景不必改注册表。
- `src/lib/svg.ts`：造元素的函数（文字、卡片、标签、路径、图标）。
- `src/lib/fx.ts`：动画函数（出现、弹出、画线、变色、压暗、沿路径流动、换文字）。
- `src/theme.ts`：画布尺寸、颜色与字号。

### 写场景的规则

播放器靠跳到某一步的结尾来实现上一步，所以时间线必须是确定的：

1. 先造好全部元素，需要先隐藏的在构建时用 `gsap.set(..., { autoAlpha: 0 })`。
2. `step('字幕')` 之后追加的补间属于这一步；第一步之前不能有补间。
3. 元素第一次出现用 `appear / pop / fadeIn / draw`，之后的变化用 `tl.to / recolor / refill / dim / pulse`。
4. 换文字用 `swapText`，不要在回调里改 `textContent`；数字滚动对 `<tspan>` 做 `textContent` 补间。
5. 虚线路径用 `fadeIn`，`draw` 会改写虚线样式。

动画区为 x 96–1824、y 170–890；页眉与字幕条由播放器绘制。颜色语义固定：绿色通过、红色不通过、琥珀色无法观察或证据不足、浅蓝冻结副本、蓝色运行中、紫色判定器与 DoG、粉色人工介入。

### 截图检查

开发服务器运行时，在浏览器控制台里：

```js
window.deck.list()                // 各场景的步数
window.deck.show('judge', 3)      // 显示 judge 场景第 3 步的结尾
```
