# 展示审查对象

审查对象：`../dist/index.html` 与 `evidence/*.png`。截图是 16 个场景最后一步的渲染结果，画布 1600×1000，逻辑画布 1920×1080。

## 整场主张

长程任务里，指令违反可以先定位到单元、规则和证据；用冻结证据做稳定判定，只改归因到技能的部分，并且只重跑变化的部分，才能把遵循度提升变成可复核的迭代。

## 已观察到的失败

1. 结果页文字重叠：`4 条不通过` 与 `11 条无法观察` 挤在一起，`$59.9` 与 `总成本` 挤在一起。
2. 封面、CI、分数、系统、边界等页面仍用并列卡片或并列条目，页面之间的关系需要听众自己拼。
3. 结果页与系统页有大量二十像素说明文字，投影上偏小。
4. 结果页把已完成实验与进行中的自迭代放在同一视觉层级，没有明确分开。
5. 数字有出处，但展示材料没有逐页索引把数字、截图、报告与命令串起来。
6. 整场没有一句反复出现的主张；页面在名词和部件之间跳转。
7. 介绍、机制、时间线、结果四段没有画面上的段落切换提示。
